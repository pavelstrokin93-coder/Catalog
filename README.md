# Каталог товаров

Адаптивный каталог на одном файле `index.html`: карточки товаров, наличие и цены, просмотр фотографий из публичных альбомов Яндекс Диска, корзина и подготовка заказа для отправки в WhatsApp.

## Как проверить

Откройте `index.html` в современном браузере или опубликуйте его через GitHub Pages. Для автоматической загрузки фотографий альбомы должны быть доступны по публичным ссылкам. Даже если API Яндекс Диска не загрузит превью, ссылка на полный альбом останется в карточке.

## Как изменить товары

В `index.html` найдите `const products = [...]` и отредактируйте названия, цены, наличие, размеры, комментарии и ссылки на альбомы. Цена указывается числом в рублях. Чтобы добавить товар, скопируйте объект товара и назначьте ему уникальный `id`.

Корзина сохраняется локально в браузере каждого посетителя. Кнопка отправки собирает заказ в сообщение WhatsApp; посетитель выбирает чат продавца и нажимает «Отправить». Для прямого открытия чата можно заменить `https://wa.me/?text=` в функции `renderCart()` на `https://wa.me/НОМЕР?text=` (номер в международном формате без `+`, пробелов и дефисов).

## Публикация через GitHub Pages

В настройках репозитория откройте **Settings → Pages**, выберите **Deploy from a branch**, затем ветку `main` и папку `/ (root)`, нажмите **Save**. После публикации GitHub покажет ссылку на сайт в этом же разделе. Отправьте эту ссылку покупателям.
